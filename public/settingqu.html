Semua data tersimpan aman di memori lokal HP (LocalStorage). Gunakan fitur ini untuk mencadangkan data berkala, memindahkan data ke HP baru, atau mengembalikan ke setelan awal.

📥 Backup Data (Ekspor JSON) 100% Data Lokal

Unduh seluruh data warga, transaksi kas, laporan surat, dan riwayat pesanan ke file .json atau kirimkan langsung via WhatsApp.

Pilih file cadangan (.json) dari memori HP untuk memulihkan seluruh data aplikasi. Sistem akan memvalidasi keutuhan file sebelum menimpa data.

Menghapus seluruh database lokal, identitas, dan riwayat di HP ini. Aplikasi akan kembali seperti baru diunduh. Tindakan ini tidak dapat dibatalkan.
